## ✨ Features

- 🎨 **Modern UI Design** - Clean and intuitive interface with gradient backgrounds
- 📱 **Responsive Layout** - Optimized for all screen sizes
- 🖼️ **Interactive Cards** - Hover effects and smooth transitions on food items
- 🍰 **Recipe Display** - Detailed ingredients and step-by-step recipes
- 🎯 **Easy Navigation** - Simple navbar with Home, Contact, and About sections

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required!

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/imvaibhav100/project1.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd project1
   ```

3. **Open the website**
   - Simply open `practice.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js http-server
     npx http-server
     ```

4. **View in browser**
   - Open `http://localhost:8000/practice.html` in your browser

## 🎨 Design Features

## 💡 Usage

### Customization

1. **Update Content**
   - Edit `practice.html` to add more sweets or modify recipes
   - Change ingredient lists and preparation steps

2. **Modify Styling**
   - Edit `style.css` to customize colors, fonts, and layouts
   - Adjust gradient colors in the navbar and footer

3. **Add Images**
   - Replace image URLs in the `<img>` tags
   - Use local images or external URLs
